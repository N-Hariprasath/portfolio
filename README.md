# 💻 HARIPRASATH N | Modern Web Developer Portfolio

A fast, responsive, and visually stunning personal portfolio built entirely with **pure HTML5, modern CSS3, and Vanilla JavaScript (ES6+)**.

---

## 🌟 Features

- **Pure HTML, CSS & Vanilla JS**: Zero frameworks, zero external runtime dependencies, ultra-fast load times.
- **Modern Glassmorphic Aesthetics**: Deep dark mode and crisp light mode with glassmorphic cards and dynamic glowing ambient mesh.
- **Interactive Typewriter Effect**: Dynamic title transitions in the hero section.
- **Filterable Technical Arsenal**: Interactive skill filters (All, Frontend, Backend, Database, Tools) with visual progress bars.
- **Featured Projects Showcase**:
  - **Placement Preparation Portal**: React, TypeScript, Tailwind CSS, Vite
  - **Food Delivery Website**: HTML5, CSS3, JavaScript (ES6+)
  - **AgriDoc — Crop Disease Diagnosis**: Java 21, Spring Boot 3, MySQL, Google Gemini API
- **Direct Resume Download**: Integrated 1-click download of `Resume.pdf`.
- **Responsive Navigation**: Clean mobile navigation with animated hamburger toggle.
- **Direct Contact Form**: Automated AJAX email delivery via FormSubmit.

## 🚀 How to Run Locally

You don't need any backend servers, databases, or build steps!

### Option 1: Direct Double Click
Simply double-click `index.html` to open it in any modern web browser.

### Option 2: Live Server / Local Web Server
If using VS Code, right-click `index.html` and select **"Open with Live Server"**, or run:

```bash
# Python
python -m http.server 3000

# Node.js (npx)
npx serve .
```

## 🌐 1-Click Deployment (GitHub Pages)

This repository is ready for free, instant static hosting on **GitHub Pages**:

1. Push this repository to GitHub (`https://github.com/N-Hariprasath/portfolio`).
2. Go to your repository **Settings** -> **Pages**.
3. Under **Branch**, select `main` and folder `/ (root)`.
4. Click **Save**. Your portfolio will be live at `https://n-hariprasath.github.io/portfolio/`!
